# Contributing

- One branch per change, named `<type>/<short-name>`, for example
  `feat/json-output` or `docs/quality-checks`.
- Every change reaches the base branch through a pull request, and is merged
  only when the checks pass.
- Use [Conventional Commits](https://www.conventionalcommits.org):
  `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`, `refactor: ...`, `chore: ...`.
- Keep commits small and focused; write the *why* in the commit body.
