# Contributing

- Work on a feature branch: `feat/<short-name>` or `fix/<short-name>`.
- `main` is protected: all changes go through a pull request with at least
  one approving review.
- Use [Conventional Commits](https://www.conventionalcommits.org):
  `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`, `refactor: ...`, `chore: ...`.
- Keep commits small and focused; write the *why* in the commit body.
